3. Core-Run-Waitlist

Bei der Waitlist-Anmeldung wird die E-Mail-Adresse verwendet, um die Anmeldung zu bestätigen und über Entwicklung, Testphase und Veröffentlichung von Core Run zu informieren. Die Anmeldung ist im Double-Opt-in-Verfahren vorgesehen.

Als Versanddienstleister ist MailerLite vorgesehen. Vertragspartner, Verarbeitungsländer, Aufbewahrungsfristen und Vereinbarung zur Auftragsverarbeitung werden vor Aktivierung ergänzt.

4. Feedbackformular

Über das Feedbackformular können eine Nachricht, eine freiwillige Kategorie und optional eine E-Mail-Adresse übermittelt werden. Eine E-Mail-Adresse ist nur erforderlich, wenn eine Antwort gewünscht wird. Als Formulardienst ist Formspree vorgesehen. Konkreter Vertragspartner, Serverregion, Aufbewahrungsfrist und Löschprozess werden vor Aktivierung ergänzt.

Bitte keine Gesundheitsdaten, Diagnosen oder andere besonders sensible Informationen in das Freitextfeld schreiben.

5. Reichweiten- und Produktanalyse

Für eine grundlegende, datensparsame Reichweitenmessung ist Cloudflare Web Analytics vorgesehen. Die tatsächlich aktivierte Konfiguration wird vor Veröffentlichung ergänzt.

Eine weitergehende Produktanalyse mit PostHog ist optional vorgesehen und wird erst nach ausdrücklicher Einwilligung geladen beziehungsweise aktiviert. Erfasst werden sollen ausschließlich technische Interaktionen wie betrachtete Abschnitte, ungefähre Verweildauer, Scrolltiefe und Formularabschlüsse. E-Mail-Adressen, Nachrichtentexte und sonstige Formularinhalte dürfen nicht in Analyse-Events übernommen werden. Die Entscheidung kann über „Analytics ändern“ angepasst werden.

6. Widerruf

Eine Einwilligung kann jederzeit mit Wirkung für die Zukunft widerrufen werden. Für die Waitlist ist hierfür insbesondere der Abmeldelink in jeder E-Mail vorgesehen.

7. Deine Rechte

Je nach gesetzlichen Voraussetzungen bestehen Rechte auf Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit, Widerspruch und Beschwerde bei einer Datenschutzaufsichtsbehörde.

8. Keine Laufdaten über diese Website

Über Waitlist und Feedbackformular werden keine Lauf-, Sensor- oder Fitnessdaten aus der Core-Run-App erhoben.
